Installation en 5 Minutes

Comment ça fonctionne

1

Achète un plan (ou commence gratuit)

Choisis ton plan parmi Gratuit, Plus, Pro ou Ultra. Pas de carte bancaire requise pour le plan gratuit.

2

Crée tes comptes API (gratuits)

Crée des comptes gratuits sur :

  • Groq - API gratuite ultra-rapide
  • Google AI Studio - Gemini gratuit
  • RapidAPI - APIs secondaires
3

Télécharge et exécute install.py

Télécharge le script d'installation automatique. Il configure tout en 2 minutes.

python3 install.py
4

Ajoute tes clés API

Mets tes clés Groq, Gemini et RapidAPI dans le fichier .env généré automatiquement.

5

Lance Karen et utilise-la

Dis simplement "et karen" et elle répond ! Montage vidéo, recherche web, appels - tout automatisé.

python3 karen_core.py
